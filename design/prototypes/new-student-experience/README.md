# Primeira experiência — protótipo navegável

Abra `index.html` diretamente. O arquivo é uma demonstração visual independente,
sem API, cadastro ou criação de atividades; o conteúdo do leitor é ilustrativo.
Na aplicação, o leitor continua incorporando o HTML integral existente.

Direção: manter o visual atual, dar destaque à escolha de cargo e ao caminho
cargo → aula → prática, apresentar o escopo e o aviso independente. Não exibir
progresso fictício. Conferir entrada, biblioteca e os estados de prática em celular
e desktop. O protótipo não é evidência de acervo aprovado ou de validação do usuário.
